# ADR 0001: Monorepo with separate backend and frontend workspaces

- Status: accepted
- Date: 2026-10-23

## Context

MergeTip has a Rust backend (API, worker, payment crates) and TypeScript clients (SvelteKit web
app, WXT browser extension). An API change and its callers should land in one PR.

## Decision

One repository:

- `backend/` — Cargo workspace (`crates/*`, `devtools/*`, `migrations/`).
- `frontend/` — pnpm workspace (`apps/web`, `apps/extension`, `packages/ui`, `packages/api-client`).
- Root — shared tooling: `openapi/` (the API contract), `docker-compose.yml`, `Makefile`,
  `deploy/`, `docs/`, `.github/`.

`openapi/openapi.json` is generated by the backend (utoipa) and consumed by the frontend
(openapi-typescript). CI fails if either side drifts.

## Consequences

Each half keeps native tooling (`cargo`, `pnpm`) and can be built in isolation; the Makefile
and CI tie them together.
